Гайд на установку ключей SSH типа ed25519
1. Проверка на наличия ключа SSH на компьютере:
~cmd
$dir %USERPROFILE%\.ssh
# Если после ввода команды не видно файлов: "id_rsa", "id_rsa.pub", "id_ed25519", "id_ed25519.pub",
то ключей нету. В таком случае, можно продолжать гайд по установке.
Также возможно ситуация, что такой директории ".ssh" может вообще не быть. В таком случае -
- узнавать у ChatGpt.
2. Генерация нового ключа SSH:
~git bash
$ssh-keygen -t ed25519 -C "your_email@example.com"
# После этой команды ввода он запросит passphrase. Это опционально. 
Если создавать его не хочется, то просто нажать "enter", если надо, 
то вписывая passphrase нужно быть внимательным, потому что то, что будет вписано будет невидимым. 
После того как passphrase введён и подтверждён, он будет использоватся, например, 
при отправке коммитов на удалённые репозитории.
3. Добавить SSH ключ в SSH агент:
• Запустить SSH агент:
~git bash
$eval "$(ssh-agent -s)"
• Добавить приватный SSH ключ к агенту:
~git bash
$ssh-add ~/.ssh/id_ed25519
4. Добавить публичный SSH  ключ на GitHub:
~git bash
$cat ~/.ssh/id_ed25519.pub
# Ключ состоит из (через пробелы):
(тип ключа) (Base64-encoded Key) (комментарий для идентификации (обычно ранее введённая почта))
• Затем скопировать содержимое, и на GitHub в разделе "SSH and GPG keys" 
ввести и подписать свой ключ. В разделе тип ключа выбрать "Authantication key".
5. Проверить соединение ключа SSH:
~git bash/vs code shell terminal
$ssh -T git@github.com
# Если всё работает корректно, должно появится следующее сообщение:
"Hi username! You've successfully authenticated, but GitHub does not provide shell access."

В случае конфликта/использования не правильного SSH ключа (если их несколько) -
- задать вопрос ChatGpt.
